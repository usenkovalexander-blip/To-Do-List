# To-Do List

Терминальное приложение для управления задачами с интеграцией OpenAI API (модель `gpt-5-mini`).

## Возможности

- Добавление задачи с названием, описанием и сроком выполнения
- Редактирование и удаление задач
- Изменение статуса (активная / выполненная)
- Фильтрация: все, активные, выполненные
- Числовые ID задач (1, 2, 3...)
- AI-помощник с учетом текущего списка задач
- Локальное хранение задач в `data/tasks.json`

## Требования

- Python 3.10+
- Ключ OpenAI API

## Установка

1. Клонируйте или скачайте проект и перейдите в его папку.

2. Создайте и активируйте виртуальное окружение:

```powershell
py -m venv venv
.\venv\Scripts\Activate.ps1
```

3. Установите зависимости:

```bash
pip install -r requirements.txt
```

4. Настройте API-ключ. Скопируйте `.env.example` в `.env` и укажите ключ:

```env
OPENAI_API_KEY=your_api_key_here
```

Ключ также можно задать через переменную окружения:

```powershell
$env:OPENAI_API_KEY="your_api_key_here"
```

## Запуск

```bash
python main.py
```

При старте приложение:

1. Выводит параметры OpenAI API (модель, temperature, max_tokens, системные инструкции)
2. Сразу открывает меню To-Do List без обязательного запроса к модели

### Параметры OpenAI

- **Модель:** `gpt-5-mini` (фиксирована)
- **Temperature:** `0.7` по умолчанию, диапазон ввода `0.0-1.0`
- **Max_tokens:** `500` по умолчанию
- **Системные инструкции:** заданы в `openai_service.py`

**Примечание о temperature:** модель `gpt-5-mini` в OpenAI API фактически принимает только `temperature=1`. Если введено другое значение из диапазона 0.0-1.0, приложение сохранит его в интерфейсе, но отправит запрос с `temperature=1` и покажет уведомление.

### Меню приложения

```text
1. Добавить задачу
2. Показать задачи
3. Редактировать задачу
4. Изменить статус
5. Удалить задачу
6. Спросить AI-помощника
0. Выход
```

### AI-помощник (пункт 6)

Перед каждым запросом к модели можно изменить:

- **Temperature** (0.0-1.0, Enter - оставить текущее значение)
- **Max_tokens** (Enter - оставить текущее значение)
- **Запрос для модели**

AI получает контекст всех текущих задач (название, описание, срок, статус). Последние введенные значения Temperature и Max_tokens сохраняются и подставляются по умолчанию в следующий запрос.

## Структура данных задачи

```json
{
  "id": 1,
  "title": "Купить кефир",
  "description": "Сходить в магазин",
  "due_date": "2026-07-29",
  "status": "active",
  "created_at": "2026-07-29T18:03:11.323488"
}
```

- `status`: `active` или `completed`
- `id` - целое число, назначается автоматически

## Структура проекта

```text
PRJ25.TodoList/
  main.py               - точка входа, загрузка .env

  .gitignore

    models.py           - модель задачи

    task_manager.py     - CRUD-операции
```

## Примечание о localStorage

В исходном промпте указан `localStorage` - это API браузера. Для терминального приложения используется локальный JSON-файл (`data/tasks.json`), что обеспечивает постоянное хранение данных между запусками.
